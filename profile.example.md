# About me

Copy this file to `profile.md` (or use **About me** in the app). Every agent reads it before replying.

Easiest way to fill it: ask ChatGPT
"Write a detailed profile of me from your memory and our past chats: who I am, what I work on,
my goals, preferences, how I like to be helped, and ongoing projects. Use headings and bullet points."

`profile.md` is listed in `.gitignore`, so it never gets uploaded.
